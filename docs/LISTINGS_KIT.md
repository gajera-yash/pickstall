# Off-site listings kit (D-134 blocks 3-4)

Ready-to-paste text for Pickstall's profiles on other sites, so every listing says the same, true thing. Search engines and AI answer engines (ChatGPT, Perplexity, Gemini, Copilot) trust a product more when many good sites describe it the same way.

**Rules for every listing**
- Use only the facts below (they match `lib/seo/site-facts.ts` and `lib/config.ts`). If a price or fact changes, update it here and on every listing.
- Every "0%" sits next to "PayPal's processing fees still apply".
- No fake reviews, no review swaps, no asking friends to post reviews without using the product. Real founding creators may review after they have used Pickstall.
- Sign up with the founder's own accounts (work email `support@pickstall.store` or your own). Claude can fill forms with you, but you create the accounts, type passwords and press the final Submit / Launch / Post.
- After each profile is live, add its https URL to `SOCIAL_PROFILES` in `lib/seo/site-facts.ts` (it becomes `sameAs` in the Organization structured data) and tick it below.

### Reddit and Quora (helpful answers, not ads)
- Answer real questions such as "Stan Store alternative?", "how to sell a digital product on Instagram?", "Gumroad fees too high?".
- Always say you are the founder. Answer the question fully first; mention Pickstall only where it fits.
- Read each subreddit's rules: many ban self-promotion or allow it only in weekly threads. Never post the same text twice.
- Example answer start:
> (Founder of Pickstall here, so I'm biased.) The main costs to compare are the monthly plan and the cut per sale. Gumroad takes 10% + $0.50 per direct sale; Stan Store has no per-sale cut but its Creator Pro plan is $99 a month...
- Log each answer: link, date, upvotes. Aim for 2 to 3 good answers a week.
